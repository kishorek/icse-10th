# Chapter Quality Assurance Checklist

## Curriculum and content

1. [ ] The examination year is recorded.
2. [ ] The official syllabus was checked.
3. [ ] Every applicable syllabus point is mapped.
4. [ ] No examinable point was silently omitted.
5. [ ] Optional enrichment is labelled.
6. [ ] Definitions, facts, formulas, reactions, processes, units, and labels were verified.
7. [ ] Textbook edition specific claims are correctly attributed.

## Teaching quality

1. [ ] Each major concept has an intuitive explanation.
2. [ ] Formal definitions and examination-ready statements are included where required.
3. [ ] Prerequisites are addressed.
4. [ ] Common misconceptions are explained.
5. [ ] Quick checks appear at useful points in the lesson.

## Memory techniques

1. [ ] Memory aids reinforce understanding.
2. [ ] Acrostics are meaningful sentences or phrases, not acronyms.
3. [ ] Each acrostic word maps to the correct target item.
4. [ ] Sequence is preserved where order matters.
5. [ ] Forced or misleading mnemonics were removed.

## Examples and assessments

1. [ ] Worked examples show the reasoning, not just the final answer.
2. [ ] Numerical answers were recalculated.
3. [ ] Each major learning outcome is assessed.
4. [ ] Question formats are varied.
5. [ ] Each question has an answer and explanation.
6. [ ] Marking points and marks are consistent.
7. [ ] Generated questions are not mislabelled as official past-paper questions.
8. [ ] Hints are progressive and answers are hidden until requested or attempted.

## Visuals and interactions

1. [ ] Every major visual has a clear learning objective.
2. [ ] Diagrams and labels are accurate.
3. [ ] Interactions work as described.
4. [ ] Reset and replay controls work.
5. [ ] Keyboard interaction is supported.
6. [ ] Essential visual information has a text alternative.
7. [ ] Motion can be paused or reduced where appropriate.

## Technical and accessibility

1. [ ] Vue templates produce semantic, structurally sound HTML.
2. [ ] No known JavaScript errors remain.
3. [ ] Navigation and internal links work.
4. [ ] Mobile, tablet, and desktop layouts were checked.
5. [ ] Keyboard focus is visible.
6. [ ] Colour is not the only way information is conveyed.
7. [ ] Progress tracking behaves as documented.
8. [ ] Reset progress works.
9. [ ] Essential content does not rely on unavailable remote resources.
10. [ ] `npm run build` completes successfully.
11. [ ] The built `dist/` is served and tested, not only the dev server.
12. [ ] The browser test suite passes, where configured.
